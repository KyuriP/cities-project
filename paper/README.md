# Manuscript

`main.tex` and `refs.bib` are the Overleaf source; `figures/` are copies of the figures produced by
`empirical/run_all.sh`: `fig_events` → `fig1_events`, `fig_schematic` → `fig2_schematic`, `fig_holdout` → `fig3_holdout`, `fig_panel` → `fig4_panel`; supplementary `fig_map` → `figS1_map`, `fig_data` → `figS2_data`, `fig_calibration` → `figS3_calibration`, `fig_hazard` → `figS4_hazard`, `fig_simulations` → `figS5_simulations` (all PDF).
Compile with `latexmk -pdf main.tex`.
