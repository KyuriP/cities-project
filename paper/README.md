# Manuscript

`empirical/run_all.sh` (`fig_map.pdf` → `fig1_map.pdf`, `fig_data.pdf` → `fig2_data.pdf`, `fig_calibration.pdf` → `fig3_calibration.pdf`,
`fig_simulations.pdf` → `fig4_simulations.pdf`, `fig_campfire.pdf` → `fig5_campfire.pdf`). Compile with `latexmk -pdf main.tex`.
